# Keirohi WinUI（凍結）

**2026-10 以降、Win / Mac とも [Keirohi.Avalonia](../Keirohi.Avalonia/) のみ運用・Release します。**

このプロジェクトは参照用にリポジトリに残しています。新機能・バグ修正は行いません。

- 起動: ルートの `通勤経路費を開く.bat`（Avalonia）を使ってください。
- 更新: [honi0907/keirohi](https://github.com/honi0907/keirohi) の WinUI Release は使わず、[honi0907/keirohi-avalonia](https://github.com/honi0907/keirohi-avalonia) の Avalonia 版に移行してください。
- データ: Windows では Avalonia 版も同じ `%LocalAppData%\Keirohi\` を使います。
